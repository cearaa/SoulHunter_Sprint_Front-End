# Soul Hunter

## Descrição
O Soul Hunter é uma plataforma sustentável gamificada desenvolvida com HTML5, CSS3 e JavaScript puro, com foco em incentivar hábitos ecológicos através de missões, rankings e progresso de usuário.

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Media Queries
