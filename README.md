# 💡 Sobre o projeto

O **Soul Hunter** é uma plataforma gamificada criada para incentivar hábitos sustentáveis através de missões, pontuações e rankings.

O projeto busca transformar ações ecológicas em uma experiência mais moderna, dinâmica e interativa, incentivando o usuário a participar de desafios sustentáveis diariamente.

A plataforma apresenta:

- Sistema de pontuação
- Dashboard gamificado
- Ranking de usuários
- Missões sustentáveis
- FAQ interativo
- Formulário de contato
- Navegação responsiva
- Interface moderna

---

# 🎯 Objetivo

Desenvolver um projeto Front-End moderno utilizando apenas:

- HTML5
- CSS3
- JavaScript puro

Aplicando conceitos de:

- Front-End Engineering
- Responsividade
- Organização de código
- Componentização
- UX/UI
- Acessibilidade básica
